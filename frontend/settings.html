Data & Backup

💾 Export Backup (JSON) Simpan seluruh transaksi, budget, kategori, dan pengaturan ke satu file untuk cadangan.
📄 Export Transaksi (CSV) Untuk dibuka di spreadsheet. File CSV tidak bisa dipakai memulihkan data — gunakan backup JSON untuk itu.
📥 Import backup & reset data Memulihkan data dari file backup dan menghapus data akan hadir di pembaruan berikutnya. Segera hadir

⚠️ File backup berisi data keuangan pribadi kamu. Simpan di tempat yang aman dan jangan dibagikan ke orang lain.

Keamanan Segera hadir

🔒 Data tersimpan di browser ini Transaksi dan budget disimpan secara lokal di perangkat ini (local storage), tidak dikirim ke server mana pun.
🛡️ Login, password & sinkronisasi cloud Belum tersedia. Akun, autentikasi, dan backup ke cloud akan hadir setelah ada server. Segera hadir

Karena data hanya ada di browser ini, menghapus data situs di browser akan menghapus transaksi dan budget kamu.
